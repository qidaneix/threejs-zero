# 3D 画板 (Three.js Zero)

一个基于 Three.js 和 React 构建的轻量级 3D 标注/画板工具，支持折线和长方体的绘制、选中及变换操作。

## 核心功能

- **基础场景**：内置 3D 渲染引擎，包含 PerspectiveCamera（透视相机）、OrbitControls（轨道控制器）、AxesHelper（坐标轴）和 GridHelper（XZ 平面网格）。
- **折线绘制 (Polyline)**：
  - 支持在网格平面上点击连续绘制折线点。
  - 选中模式下可点击折点并实时移动调整位置。
- **长方体绘制 (Cuboid)**：
  - 基于 XZ 平面上的三点及高度定义长方体。
  - 自动计算变换矩阵（平移、旋转、缩放）。
- **交互与变换**：
  - **精准选中**：采用屏幕像素距离过滤算法，支持高精度的边缘选中，避免大面积误触。
  - **TransformControls**：支持对选中的长方体进行移动 (Translate)、旋转 (Rotate) 和缩放 (Scale)。
- **持久化存储**：所有绘制和修改操作实时同步至 `localStorage`，支持页面刷新后自动还原。
- **响应式设计**：画布自动适应窗口大小变化。

## 操作指南

### 模式切换
- `Ctrl + Q`：切换到 **选中模式** (Select)
- `Ctrl + D`：切换到 **绘制折线模式** (Draw Polyline)
- `Ctrl + C`：切换到 **绘制长方体模式** (Draw Cuboid)
- `Escape`：快速返回选中模式

### 绘制操作
- **绘制折线**：在 `Draw Polyline` 模式下，点击左键添加点，按下 `Space` (空格) 完成当前折线绘制。
- **绘制长方体**：在 `Draw Cuboid` 模式下，依次点击三个点确定底面方向和长宽，点击第四个点（或移动）确定高度。

### 选中与编辑
- **选中**：在 `Select` 模式下，鼠标悬停在物体边缘（变黄）时点击左键即可选中（变粉）。
- **编辑折线**：选中折线后，点击其折点可进入移动模式。
- **编辑长方体**：选中长方体后，使用以下快捷键切换变换工具：
  - `T`：移动工具
  - `R`：旋转工具
  - `S`：缩放工具

## 技术栈

- **框架**：React 19
- **3D 引擎**：Three.js r180
- **构建工具**：Rsbuild (高效的 Web 构建工具)
- **UI 组件**：Ant Design
- **语言**：TypeScript
